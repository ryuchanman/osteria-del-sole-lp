## 4. 声（ボイス）ガイド

### 4-1. トーン

- **温度は低め。笑いはツッコミで作る。** 感嘆符は1投稿に1個まで
- 数字は必ず具体（「月5万」「時給1,050円」「48時間」）。丸めない
- 相手を「ママ」「あんた」とは呼ばない。「うちと同じ人」「読んでる人」

### 4-2. 語彙表（使う／使わない）

| 使う（日常関西弁） | 使わない |
|---|---|
| うち、〜やねん、〜やで、〜やん、〜やろ、〜してん、〜へん | わし、〜でんがな、〜まんねん、なんでやねん（多用） |
| ほんま、めっちゃ、しんどい、えらい（＝大変）、ちゃう、あかん、ええ | 儲かる、稼げる（連発）、誰でも、絶対、簡単 |
| 〜してもろて、〜しといて、〜やった | 標準語の「〜ですよね」「〜しましょう」 |
| AIさん、ChatGPTくん | AIツール、生成AI（固い） |
| 知らんけど（感情の話のオチのみ） | 知らんけど（数字・実績のオチ） |

### 4-3. 文の型

- **1行目は結論か数字か本音**。前置き禁止
- 2〜4行で改行多め。1行25字以内
- 最後は「質問」か「ひとこと本音」で締める。CTAは3投稿に1回まで

### 4-4. 実例（同じ内容の書き分け）

```
✕ 標準語：ChatGPTは無料版で十分です。有料版に課金しなくても稼げます。
✕ コテコテ：ChatGPTなんか無料でええねんて！課金なんかせんでもガンガン稼げるでほんま！
◎ 採用：ChatGPT、無料版でええで。
        課金してからやないと稼げへんって言うてる人、
        なんか売りたいだけちゃう？
```

## 7. 炎上・信頼リスクと対処

| リスク | 対処 |
|---|---|
| 「大阪弁がわざとらしい」 | 語彙表の頻出5語に絞る。地元民が読んで違和感ないレベルを維持。運用者が関西出身でない場合は関西出身者に月1で校正依頼 |
| 「子ども晒し」批判 | 顔・実名・園名・学校名は出さない。子どもの名前は設定上の仮名と明記しない（「長男」「次男」で通す） |
| 「実績は本当か」 | 週次ログを欠かさない。売上0円も出す。スクショは数字を加工しない |
| 「AI副業＝詐欺」の巻き添え | 「月100万言わへん」をプロフに明記。他アカを批判せず、自分の基準だけ言う |
| 景表法・ステマ規制 | アフィ投稿は冒頭に「PR」。「誰でも」「必ず」「簡単に」を使わない |
